# 📊 Sales Data Analysis and Forecasting

**Algonive Data Analytics Internship – Task 2**

---

## 📌 Project Overview

This project focuses on analyzing historical sales data to identify trends, patterns, and insights, and to forecast future sales revenue.
The analysis helps businesses understand customer purchasing behavior and make data-driven decisions related to inventory planning and marketing strategies.

---

## 🎯 Objectives

* Perform data cleaning and preprocessing
* Conduct exploratory data analysis (EDA)
* Apply feature engineering for time-based analysis
* Analyze sales trends over time
* Forecast future sales using a simple predictive model

---

## 📂 Dataset

* **File Name:** `sales_data.csv`
* **Description:** Transaction-level retail sales data

### Key Columns Used

* `Date` – Transaction date
* `Product Category` – Category of the product sold
* `Quantity` – Units sold
* `Price per Unit` – Price of each unit
* `Total Amount` – Total sales value per transaction

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

---

## 🔍 Project Workflow

1. Data loading and inspection
2. Data cleaning and preprocessing
3. Feature engineering (year, month extraction)
4. Exploratory data analysis (EDA)
5. Aggregation of transaction data into monthly sales
6. Sales trend analysis
7. Sales forecasting using Linear Regression
8. Visualization of actual vs forecasted sales

---

## 📈 Sales Forecasting Approach

A **Linear Regression** model is applied to monthly aggregated sales data to identify trends and forecast future sales.
This approach is simple, interpretable, and suitable for business-level forecasting.

---

## 📊 Visualizations Included

* Sales by product category
* Sales trends over time
* Monthly sales analysis
* Actual vs forecasted sales comparison
